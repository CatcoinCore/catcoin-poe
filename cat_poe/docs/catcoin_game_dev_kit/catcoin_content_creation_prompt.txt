
CATCOIN RUNNER – CONTENT CREATION PROMPT
========================================

This prompt defines all visual assets required by the CatCoin Runner game.

The game engine architecture is defined in the separate document:

"CatCoin Game Engine Architecture Prompt"

All generated assets must be compatible with that architecture.

Game Overview
-------------
Game Type:
Hybrid Auto-Runner Platformer

Platform:
Flutter + Flame

Orientation:
Landscape

Art Direction – Character Consistency
-------------------------------------

The game MUST use the same CatCoin mascot used in the existing mining app.

Reference images from the app represent the official mascot.

Do NOT redesign the character.

Style
-----
2D cartoon
soft rounded shapes
expressive eyes
minimal outlines
mobile friendly readability

Technical Requirements
----------------------

All assets must be:

PNG
True transparent background (alpha channel)

No checkerboard background.
No solid background color.

Sprite sheets must work with Flame SpriteAnimation.

Recommended frame size:
256x256 per frame.

------------------------------------------

Frame 8 Flight

Back legs touch ground

Frame 12 Loop
