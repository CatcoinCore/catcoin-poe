
CATCOIN RUNNER – BALANCING & REWARD ECONOMY BIBLE
=================================================

Purpose
-------
Define the reward economy and balancing rules for CatCoin Runner so that:
• rewards feel meaningful to players
• the CatCoin economy remains stable
• farming and cheating are discouraged
• gameplay progression stays engaging

Currency Model
--------------
1 CAT = 100,000,000 catoshi

Game Conversion:
1 in‑game coin = 1 catoshi

All coins collected during gameplay are stored in the game reward ledger.
They are NOT credited directly to the main wallet balance.

Reward Storage Model
--------------------

Each game session records rewards independently.

Tables:

game_sessions
-------------
id
user_id
session_token
start_time
end_time
score
coins_collected
validated

game_rewards
------------
id
user_id
session_id
reward_catoshi
created_at

Dashboard Calculation
---------------------

Total Game Rewards =

SUM(reward_catoshi)
FROM game_rewards
WHERE user_id = ?

This value appears on the mining dashboard as:

Game Rewards (Catoshi)
Mining Rewards (CAT)
Total Balance (CAT)

Reward Philosophy
-----------------

The game should reward skill and engagement, not just time.

Three reward drivers:

1. Distance travelled
2. Coins collected
3. Skill bonuses

Base Coin Distribution
----------------------

Recommended coin generation rate:

Average: 40 – 80 coins per minute

Upper cap:
120 coins per minute

Anything higher risks reward inflation.

Session Length Targets
----------------------

Typical session length:

1 – 3 minutes

Maximum expected session:

5 minutes

Example reward ranges:

Session Time    Expected Coins

1 minute        40 – 70
2 minutes       80 – 120
3 minutes       120 – 200
5 minutes       200 – 350

Distance Scaling
----------------

Distance       Coin Multiplier

0–500m         1.0x
500–1500m      1.1x
1500–3000m     1.25x
3000m+         1.5x

Skill Bonuses
-------------

Players may earn extra catoshi for skilled actions.

Examples:

Perfect Jump Bonus +2 catoshi
Enemy Dodge Bonus +3 catoshi
Turbo Chain Bonus +5 catoshi

These bonuses must remain small to avoid economy inflation.

Daily Reward Limits
-------------------

Maximum daily reward per user:
10,000 catoshi

Example:

10000 catoshi = 0.0001 CAT

After the cap is reached:
• rewards stop accumulating
• gameplay remains playable

Session Validation Rules
------------------------

Before rewards are accepted, the backend must validate:

Coin Rate Check
---------------
coins_collected / play_time

If > 2 coins per second → suspicious

Score vs Distance Check
-----------------------
Score must scale logically with distance.

Jump Frequency Check
--------------------
Maximum allowed jumps:
3 jumps per second

Speed Validation
----------------
Player speed must stay within game engine limits.

Session Token Check
-------------------
Each session token can only be submitted once.

Reward Claim Mechanism
----------------------

Game rewards should not auto-transfer to the wallet.

Instead:

User accumulates catoshi in the ledger.

Optional future feature:

Claim Game Rewards → Wallet

Example rule:

Minimum claim threshold:
10,000 catoshi

Seasonal Leaderboards
---------------------

Optional system:

Top players receive bonus rewards.

Example:

Rank 1 → 100,000 catoshi
Rank 2 → 50,000 catoshi
Rank 3 → 25,000 catoshi

Inflation Protection
--------------------

Three primary safeguards:

1. Daily reward cap
2. Server validation
3. Procedural coin spawn limits

Balancing Philosophy
--------------------

Rewards should feel:
• fair
• skill based
• meaningful
• not easily farmable

The goal is player engagement first, rewards second.

End Goal
--------

Create a sustainable micro‑reward system where:

• players enjoy the game
• CatCoin retains value
• cheating is minimized
• rewards scale with skill
