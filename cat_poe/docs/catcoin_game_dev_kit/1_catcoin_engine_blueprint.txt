CATCOIN RUNNER – ENGINE BLUEPRINT PROMPT
========================================

Project Context
---------------
The CatCoin Runner game is an add-on module inside an existing CatCoin mining app.

Existing stack:
Frontend: Flutter
Backend: Python FastAPI
Database: PostgreSQL

The mining app already contains:
- Wallet system
- Leaderboard
- User accounts

The game must integrate with these systems.
Game assets must be downloaded only when the user launches the game for the first time.
The base mining application must remain lightweight.

Game Type
---------
Hybrid Auto-Runner Platformer

Orientation:
Landscape 16:9

Game Engine:
Flutter + Flame

Core Gameplay
-------------
Side-scrolling auto runner.

Player controls:
Tap → Jump
Tap again → Double jump

Player collects coins, avoids enemies, and activates turbo.

Currency Model
--------------
1 CAT = 100000000 catoshi
1 in-game coin = 1 catoshi

Coins are NOT added directly to the wallet.
Instead they are stored in a game reward ledger.

Reward Flow
-----------
Game session start
→ FastAPI issues session token
→ player plays game
→ client submits score and coins
→ backend validates results
→ reward stored as catoshi in ledger

Core Systems
------------
Player controller
Animation state machine
Enemy system
Coin system
Turbo system
Collision system
Procedural level generator
HUD system
Camera system

Player Controller
-----------------
The player character is the CatCoin mascot.

Movement Model
• constant forward auto-run
• jump
• double jump
• fall
• landing recovery

Physics
• gravity based
• platform collision detection
• obstacle collision detection

Animation State Machine
-----------------------
States:
idle
run
jump
double_jump
fall
land
turbo
damage
victory

Enemy System
------------
Enemies spawn via procedural chunks.

Enemy types:
• drone
• robo vacuum
• dog

Each enemy has:
• idle animation
• movement
• attack trigger
• destroyed animation

Coin System
-----------
Coins represent CatCoin micro rewards.
1 coin = 1 catoshi

Collision with player:
• increment coin counter
• spawn particle effect
• update HUD

Turbo System
------------
Turbo is activated by filling a meter via coin collection.

Turbo effects:
• temporary speed increase
• animation change
• particle trail

Collision System
----------------
Player collision types:
player vs ground
player vs coin
player vs enemy
player vs obstacle

Camera System
-------------
Side-scrolling camera.
Player remains left-of-center to provide forward visibility.

Procedural Level Generator
--------------------------
Level is generated using chunk spawning.

Chunk contains:
• platforms
• coin trails
• obstacles
• enemies

Difficulty increases over distance.

FastAPI Integration
-------------------
Start Session
POST /game/start-session

Submit Session
POST /game/submit

Session Data
------------
score
coins_collected
play_time
game_version

Server validates score before writing reward.

Reward Model
------------
1 CAT = 100000000 catoshi
1 coin = 1 catoshi

Rewards stored in ledger table:
game_rewards
