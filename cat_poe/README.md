# cat_poe

Catcoin PoE Flutter client.

## Open-source / fork setup

- **Firebase (Android):** `android/app/google-services.json` is **gitignored**. Start from `android/app/google-services.json.example` and follow **[docs/firebase_fork_setup.md](docs/firebase_fork_setup.md)**.
- **Build commands (dev / staging / prod):** **[docs/BUILD_RUNBOOK.md](docs/BUILD_RUNBOOK.md)**.
- **Security:** report vulnerabilities per the repo root **`SECURITY.md`** (do not use public issues for exploitable bugs).
