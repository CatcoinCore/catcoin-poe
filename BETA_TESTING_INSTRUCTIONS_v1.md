# Catcoin PoE - Beta Testing Instructions

Welcome to the Beta Testing program for Catcoin PoE! We appreciate your help in making our app the best it can be. Please follow these instructions to test the app and report any issues.

## 1. Getting Started

### Installation
1.  **Android**: Play Store listing for your package ID, e.g. `https://play.google.com/store/apps/details?id=YOUR.PACKAGE.NAME`
2.  **iOS** (if applicable): NA

*Note: If you are installing an APK directly, ensure you have "Install from unknown sources" enabled.*

## 2. What to Test

We need you to explore all major features of the app. Please go through the following checklist:

### 🔐 Authentication
- [ ] **Sign Up**: Create a new account. Check if the email verification code arrives and works.
- [ ] **Login**: Log out and log back in.
- [ ] **Password Reset**: Try the "Forgot Password" flow to ensure you can reset your credentials.

### ⛏️ Mining & Dashboard
- [ ] **Start Mining**: Tap the mining button. Verify the animation plays and the session starts.
- [ ] **Timer**: Check if the countdown timer works correctly.
- [ ] **Ads**: If an ad appears, watch it to see if it rewards you or boosts the session correctly.
- [ ] **Background Mode**: Minimize the app while mining and open it later. Check if the timer continued correctly.

### 💰 Wallet & Payouts
- [ ] **Balance**: Check if your balance updates after a mining session ends.
- [ ] **Payout History**: View your transaction history in the "Wallet" or "History" tab.
- [ ] **Withdrawal (Mock)**: Try to initiate a withdrawal (if enabled) and see if the UI flows correctly.

### 🎁 Rewards & Missions
- [ ] **Daily Rewards**: Claim your daily check-in reward.
- [ ] **Missions**: Attempt to complete a mission (e.g., "Follow us on Twitter"). verify the status updates to "Completed".

### 👥 Referrals
- [ ] **Share Link**: Use the "Invite Friend" button to share your referral link.
- [ ] **Referral Code**: If possible, have a friend sign up with your code and check if your referral count increases.

### 👤 Profile & Settings
- [ ] **Update Info**: Change your profile picture or update your username.
- [ ] **App Settings**: Toggle sound/notifications if available.

## 3. How to Report Bugs

If you find a bug or a crash, please report it immediately!

**Reporting Channels:**
- **Google Play Feedback**: Use the feedback button in the Play Store testing section.
- **Email**: Send details to [Insert Support Email].
- **Discord**: Join our server and post in the `#beta-feedback` channel: [Insert Discord Link]

**What to include in your report:**
1.  **Description**: What happened? What did you expect to happen?
2.  **Steps to Reproduce**: Detailed steps so we can see the bug ourselves.
3.  **Device Info**: Your phone model (e.g., Samsung S21) and Android version.
4.  **Screenshots/Screen Recording**: Visual proof is extremely helpful!

## 4. Feedback We Need

Beyond bugs, we want to know:
- **Usability**: Is the app easy to navigate? Is anything confusing?
- **Performance**: Does the app feel slow or laggy? Does it drain your battery?
- **Design**: Do you like the look and feel? any visual glitches?

**Thank you for being a vital part of the Catcoin PoE community! 🚀**
