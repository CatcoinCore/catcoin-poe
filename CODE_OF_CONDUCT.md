# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code of conduct.

The full text is published at:
**<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>**

It is reproduced in this repository **by reference** rather than inline. Read it before contributing — by participating in this project (issues, pull requests, discussions, events, or any other channel run by the maintainers) you agree to follow it.

## Scope

The Code of Conduct applies in all project spaces and when an individual is officially representing the project or its community in public.

## Reporting

If you experience or observe behaviour that violates the Code of Conduct, please report it privately. Use the project's security disclosure channel listed in [SECURITY.md](SECURITY.md) — that channel is also accepted for conduct reports and reaches the maintainers without going through public issues.

Reports should include:

- What happened, when, and where (which channel / repo / event).
- Who was involved (handles or names if you have them).
- Any links, screenshots, or context that help us understand the situation.

Maintainers will acknowledge reports promptly and decide on response (which may include a private warning, temporary suspension, or permanent ban from project spaces) consistent with the Covenant's enforcement guidelines.
